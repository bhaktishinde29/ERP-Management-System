📌 Project Overview
The ERP Management System is a full-stack web application developed using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). It helps organizations manage business operations such as products, customers, suppliers, employees, sales, purchases, invoices, and user roles from a single platform.
The system provides secure authentication, role-based access control, and an interactive dashboard to simplify day-to-day business management.

🚀 Features
User Authentication (JWT)
Role-Based Access Control (Admin & Employee)
Dashboard with Business Statistics
Product Management (Add, Edit, Delete, Search)
Customer Management
Supplier Management
Sales Order Management
Purchase Order Management
Goods Receipt Note (GRN)
Invoice Generation
Employee/User Management
Responsive User Interface
Secure REST API
